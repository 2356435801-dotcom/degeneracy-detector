# Cartographer 2D SLAM 退化检测改进项目开发记录

## 项目说明

本项目研究如何提升 Google Cartographer 2D SLAM 在长直走廊等退化环境中的鲁棒性，包含 ROS 2 Humble 退化检测节点、ROS 无关的 C++ 算法核心、Cartographer 前端观测与后续前后端策略和实验验证。每篇日期日志记录当日完成的独立开发任务及其真实验证结果。

## 开发阶段

1. ROS 2 环境与 Cartographer 构建。
2. 退化检测节点 ROS 2 迁移。
3. 纯 C++ 核心算法库抽离。
4. Cartographer 前端观测式集成。
5. 前端自适应匹配策略。
6. 后端退化感知约束筛选。
7. 实验验证与论文整理。
